디코딩, 프레임 추출, GIF 인코딩, 데스크톱 Live Photo 패키징은 브라우저 안에서 처리하며 영상 파일을 서버로 업로드하지 않습니다. 편집 중 메모리와 임시 로컬 URL을 사용합니다. 페이지를 닫으면 편집이 끝나며 다운로드한 파일은 사용자가 삭제합니다.

개인정보 및 쿠키

Google AdSense와 쿠키를 사용합니다. Google과 제3자는 이 사이트와 다른 사이트 방문 기록에 기반한 광고에 쿠키를 사용하고 IP, 브라우저, 기기, 광고 상호작용 정보를 처리할 수 있습니다. 로컬 변환은 사이트 전체에 쿠키가 없다는 뜻이 아닙니다.

아래 Google 광고 설정에서 맞춤 광고를 끌 수 있고 브라우저 쿠키 설정도 사용할 수 있습니다. 광고 제공은 Google 설정과 해당 동의 요건에 따릅니다. 코드가 있다고 승인이나 광고 노출이 확인된 것은 아닙니다.

개인정보 및 데이터

GitHub Pages가 호스팅하고 Cloudflare가 배포, 보안, 에지 요청 통계를 제공합니다. IP, URL, 브라우저, 시간, 상태, 추정 지역을 처리할 수 있습니다. 앱에는 Google Analytics나 Cloudflare Web Analytics 비콘이 설치되어 있지 않습니다. 보안 스크립트는 별개입니다.

Cloudflare의 2026년 10월 2일 정책: 모든 플랜 분석 최소 30일, Free/Pro의 적응형 HTTP·보안·DNS 데이터 최소 31일, 한 번의 조회 최대 30일입니다. 집계 데이터에는 별도 한도가 있고 이 사이트의 구체 설정은 미확인입니다. 조회 기간이 전체 원시 로그 삭제 기한은 아닙니다. 기타 Cloudflare·GitHub·Google 로그와 광고 데이터는 제공자 정책, 목적, 설정과 의무에 따르며 통일된 고정 기간은 미확인입니다.

요청 및 피드백

Cloudflare Workers/D1이 이름, 유형, 본문, 언어, 시간, 검토 상태와 악용 방지 식별자를 저장합니다. 댓글 표에는 원시 IP 대신 매일 바뀌는 키 기반 해시를 저장합니다. 24시간 지난 해시는 다음 댓글 삽입 때 지우므로 새 제출이 없으면 더 오래 남습니다. 본문·검토 기록은 자동 만료되지 않으며 거절은 숨김이지 삭제가 아닙니다. 승인된 이름, 유형, 본문, 날짜만 공개하고 영상이 아닌 텍스트 JSON만 받습니다.

메일 서비스는 발신 주소, 본문, 자발적으로 첨부한 파일을 처리하며 고정 자동 만료 설정은 없습니다. Ko-fi, Alipay, WeChat Pay는 후원·결제 정보를 별도 처리하고 사이트는 카드 인증정보를 받지 않습니다. 의견이나 후원 없이 이용할 수 있고 쿠키, 로컬 파일 삭제와 이메일을 통한 검토·삭제 요청이 가능합니다.
