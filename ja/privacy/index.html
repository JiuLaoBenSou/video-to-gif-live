端末内で変換 · 動画のアップロード不要

動画のデコード、フレーム取得、GIF生成、PCの Live Photo 構築はブラウザ内で行い、動画をサーバーへアップロードしません。編集中はメモリと一時的なローカルURLを使用します。閉じると編集は終了し、ダウンロード済みのファイルは自分で削除します。

プライバシーと Cookie

Google AdSense と Cookie を使用します。Google などの第三者は当サイトや他サイトの閲覧履歴に基づく広告に Cookie を使い、IP・ブラウザ・端末・広告操作を処理する場合があります。ローカル変換はサイト全体が Cookie 不使用という意味ではありません。

下記 Google 広告設定でパーソナライズ広告を無効にでき、ブラウザの Cookie 設定も利用できます。広告は Google の設定や適用される同意要件に依存し、コードの存在は審査承認や広告表示を意味しません。

プライバシーとデータ

GitHub Pages がホストし、Cloudflare が配信・安全対策・エッジのリクエスト統計を提供します。IP、URL、ブラウザ、日時、状態、推定地域を処理する場合があります。当サイトは Cloudflare Web Analytics のブラウザビーコンでページ閲覧と性能を測定します。選択した動画は送信しません。分析ビーコンは安全対策スクリプトとは別で、Google Analytics は導入していません。ビーコンデータの保存は Cloudflare の方針とアカウント設定に従い、当サイト固有の期間は未確認です。

Cloudflare の2026年10月2日の方針では全プランで分析データが最低30日、Free/Proの適応型HTTP・安全・DNSデータは最低31日、1回の照会は最大30日です。集計データは別規定で、当サイト固有の設定は未確認です。照会期間は全生ログの削除期限ではありません。その他のCloudflare・GitHub・Googleのログや広告データは各社の目的・方針・設定・義務に従い、統一した固定期限は未確認です。

ご要望・フィードバック

Cloudflare Workers/D1 は名前、種類、本文、言語、日時、審査状態と不正利用対策識別子を保存します。コメント表に生IPを保存せず、日替わりの鍵付きハッシュを計算します。24時間超の古いハッシュは後続の投稿時に消すため、投稿がなければ残ります。本文・審査記録は自動失効せず、却下は非表示で削除ではありません。承認後の名前・種類・本文・日付のみ公開。文字JSONのみ受け付け、動画は受け付けません。

支援

メールサービスは送信元・本文・自発的に添付したファイルを処理し、固定の自動失効は設定していません。Ko-fi・Alipay・WeChat Pay は支援・決済情報を各自処理し、サイトはカード認証情報を受け取りません。投稿や支援なしでも利用でき、Cookieの削除、ローカルファイル削除、メールでの削除相談が可能です。

匿名の操作集計

有効な場合、動画読み込み、変換開始、成功・失敗・キャンセル、ダウンロード操作を、言語・出力・端末・流入元・容量の固定区分で集計します。ランダムな選択・試行IDはページのメモリ内のみで使い、サーバー上のイベントは24時間後に削除対象になります。動画、サムネイル、ファイル名、パス、エラー原文、参照元の完全URL、支払い情報、永続的な訪問者ID、IPは集計テーブルに保存しません。ダウンロード操作は保存完了の証明ではありません。毎時とリクエスト時に期限切れデータを削除しますが、中断で遅れる場合があります。日次合計はUTCの90日分を保持します。ローカルのテスト用DBは本番と分離されます。ホスティング・接続ログ・提供元のバックアップには前述の別の方針が適用されます。
