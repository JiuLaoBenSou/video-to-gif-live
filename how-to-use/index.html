How to use

Choose a short moment. Trim it, tune it, then check the actual download.

1. Choose a video

Open the converter and choose a local file, or drag one onto the preview. The input limit is 200 MB. MP4, MOV and WebM can work when your browser supports their video codec; a filename extension alone does not guarantee decoding. Wait for the preview and duration to appear. Your file stays on your device.

2. Trim the moment

Under the preview, drag either end of the yellow selection to change the start or end. Drag the whole selection to keep its length while moving it along the video. The time fields give another way to set the interval. GIF input selections can be up to 15 seconds. A short selection is usually easier to share than a whole scene.

3. Set the output and create

Choose GIF. Pick Original, 4K, 2K (2560 × 1440), 1080, 720, 480 or 360. Output keeps the video’s shape and orientation; higher-than-source options are disabled to avoid upscaling. Turn the frame-rate dial between 1 and 30 FPS. Higher FPS supplies more frames, increasing work and often file size.

Set speed from 0.25× to 4× and choose Forward, Reverse or Ping-pong. The source preview still plays forward; check the transformed motion in the generated GIF. Slow motion and the return journey use more output frames. The tool limits output to 450 frames and also checks its processing budget; reduce the clip, size or FPS if a limit is reached.

For an upload limit, enable Target file size and enter 1 KB–64 MB. Units are decimal: 1 MB means 1,000,000 bytes. The converter tries smaller palettes and, if needed, smaller dimensions while keeping your selected FPS. It checks the final byte count and reports failure when it cannot meet the target. There is no manual color-count or dithering switch.

Click Create GIF, wait for encoding, and review the animation, dimensions and actual size before downloading. GIF has no audio. Cancel stops a conversion while retaining the current edit; browser memory and encoding support can still limit what a device handles.

Three useful starting points

A quick reaction

Trim 1–3 seconds, try 360 or 480 and 12–15 FPS, then use Ping-pong if the action should return. Check the final loop; these settings are starting points, not a size guarantee.

A small attachment

Set a 1 MB or 5 MB target, shorten the selection and start at 480. If details become muddy, allow a larger file or keep a shorter moment. The encoder reduces colors and dimensions automatically.

A product demonstration

Keep one clear action and enough resolution for the important detail. Try 720 and 15–20 FPS, then compare readability and download size. Screen text and gradients can be affected by GIF’s palette.

Desktop Live Photo is a separate output

For video → Live Photo, use desktop Chrome or Edge with H.264 encoding support, select at most 3 seconds and choose a cover frame. This version creates a silent ZIP containing LivePhoto.pvt. Follow the result instructions: transfer the ZIP to iPhone, extract it in Files and open the complete package to use the available save-to-Photos action. Device behavior can vary; this is not a promise of compatibility with every OS version. Direct mobile Live Photo export is planned for a future app.

If you already have an iPhone Live Photo and want a GIF, read the iPhone input guide. For color and file-size trade-offs, read GIF’s 256-color limit.
